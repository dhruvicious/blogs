# dhruvicious-blogs

A custom static blog generator and site, built with Bun and TypeScript. It includes a small JSX-like rendering system in `src/tsx.ts`, Djot content rendering, syntax highlighting, RSS generation, and a static file build.

Write posts as `.dj` files in `content/posts/`, then run:

```console
$ bun run build
$ bun run serve
```

Update the starter pages in `content/` and site identity settings in `src/site.ts`.
